Attributor - Expert Mass Spectrometry Analysis Tool

A comprehensive Igor Pro-based software package developed at IPAG Grenoble (Institut de Planétologie et d'Astrophysique de Grenoble, France) for precise molecular formula attribution and isotopic distribution simulation in high-resolution mass spectrometry.

Introduction

Attributor is a specialized Igor Pro (WaveMetrics) software package designed for expert-level mass spectrometry data analysis. It provides comprehensive tools for molecular formula building, isotopic distribution simulation, and experimental data comparison in the fields of astrophysics, analytical chemistry, and high-resolution mass spectrometry.

Primary Applications

Attributor excels in:

  • Molecular Astrophysics: Identification and characterization of complex organic molecules in interstellar and circumstellar environments, particularly in meteorite analysis and astrochemical studies
  • High-Resolution Mass Spectrometry: Precise mass defect analysis and isotopic pattern matching for unknown compound identification
  • Chemical Analytics: Detailed molecular formula attribution from experimental mass spectra with isotopic resolution
  • Research Applications: Support for laboratory analysis in planetary science, cosmochemistry, and related disciplines

Key Capabilities

  • Interactive Molecular Formula Construction: Build complex molecular formulas through an intuitive periodic table interface with real-time feedback
  • High-Precision Isotopic Distribution Simulation: Calculate theoretical isotopic patterns using advanced combinatorial algorithms with natural isotope abundances
  • Real-Time Experimental Comparison: Overlay simulated spectra with experimental data for immediate visual verification
  • Mass Calibration: Automatically align experimental spectra with theoretical predictions using sophisticated calibration algorithms
  • Multi-Molecule Comparison: Compare multiple molecular hypotheses simultaneously in the aggregator window
  • Mass Defect Analysis: Visualize and analyze mass defects using specialized DMVM (Mass Defect vs m/z) plots
  • MS/MS Mode Support: Advanced tandem mass spectrometry analysis capabilities

Scientific Context

Attributor was developed in response to the growing need for precise molecular identification in astrophysical research. As mass spectrometry instruments achieve ever-higher resolutions (Orbitrap, FT-ICR MS), the ability to distinguish between molecular formulas based on subtle isotopic patterns becomes crucial. This tool bridges the gap between experimental mass spectrometry data and theoretical molecular composition, enabling researchers to identify unknown compounds in complex mixtures, validate molecular assignments through isotopic pattern matching, quantify isotopologue contributions, and perform high-precision mass defect analysis.

Scientific Foundations

Understanding the fundamental scientific concepts behind Attributor is essential for expert-level usage and interpretation of results.

Isotopic Distribution Theory

Expert Note: Polynomial Generator Approach

Attributor implements the polynomial generator method for isotopic distribution calculation, which is mathematically rigorous and computationally efficient. For a molecule with formula CaHbNcOdSe..., the generating function for each element is: Pelement(x) = (p0 + p1xm1 + p2xm2 + ...) where pi is the natural abundance of isotope i with mass shift mi relative to the monoisotopic mass. The total distribution is the product: Ptotal(x) = PRODUCT of Pelement(x)count.

Computational Optimization: The software uses Fast Fourier Transform (FFT) for efficient polynomial multiplication, enabling calculation of distributions for molecules with >50 atoms in milliseconds.

Isotopic Abundance

Definition: The natural occurrence percentage of each isotope of an element in the Earth's environment.

Significance: Determines the relative intensity of isotopic peaks in mass spectra. Even low-abundance isotopes (e.g., 13C at 1.07%, 2H at 0.0115%) produce detectable signals in high-resolution instruments.

Example: Carbon has two stable isotopes: 12C (98.93%) and 13C (1.07%). For a molecule with 10 carbon atoms, the probability of having exactly k 13C atoms is given by the binomial distribution: P(k) = C(10,k) (0.0107)k (0.9893)10-k

Attributor Implementation: Uses precise isotopic abundance values from IUPAC 2021 standards.

Mass Defect

Definition: The difference between the exact mass of an ion and its nominal (integer) mass, expressed in millidaltons (mDa) or parts-per-million (ppm).

Formula: Mass Defect = Exact Mass - round(Exact Mass)

Significance: Unique to each element and its isotopes. Mass defect patterns allow differentiation between compounds with the same nominal mass but different elemental compositions.

Example Values: H: +0.007825 Da, C: 0.000000 Da, N: +0.003074 Da, O: -0.005085 Da

Monoisotopic Mass

Definition: The mass of a molecule calculated using the exact mass of the most abundant isotope of each element.

Constitution: Typically uses 12C, 1H, 14N, 16O, 32S, 31P, etc.

Importance: The monoisotopic peak is usually the most intense peak in the isotopic cluster for organic molecules.

Calculation: Attributor uses exact isotopic masses from the AME2020 atomic mass evaluation.

High-Resolution Mass Spectrometry

Resolution: Ability to distinguish between two peaks of slightly different m/z values. Defined as R = m/DELTA_m where DELTA_m is the peak width at half maximum (FWHM).

Resolving Power: Attributor is optimized for instruments with resolving power >100,000 (e.g., Orbitrap, FT-ICR MS), where isotopic fine structure is resolved.

Mass Accuracy: Typical high-resolution instruments achieve <1 ppm mass accuracy, enabling confident molecular formula assignments.

Expert Note: Isotopic Fine Structure

Chlorine and Bromine: These elements exhibit distinctive M and M+2 patterns due to their two abundant isotopes with ~3:1 ratio for Cl and ~1:1 ratio for Br. Attributor correctly calculates these patterns, which are crucial for identifying halogenated compounds.

Sulfur: The 34S isotope at 4.25% abundance produces a visible M+2 peak, approximately 4.4% of the M peak for a single sulfur atom.

High-Mass Elements: For elements with A>100, isotopic patterns become complex due to multiple isotopes. Attributor handles these cases using the full isotopic distribution database.

Standard Workflow

Attributor is designed for an efficient, iterative workflow that allows experts to rapidly test hypotheses and refine molecular assignments.

Standard Analysis Procedure

1

Load Experimental Data

Use AdvancedManager to load your experimental mass spectrum.

Supported Formats:

  • Igor Pro Binary: .ibw files with wave data
  • ASCII Text: Tab- or space-delimited files with m/z and intensity columns
  • CSV: Comma-separated values with appropriate headers

Data Requirements: m/z values must be in ascending order for proper visualization.

2

Build Molecular Formula

Click on elements in the periodic table to construct your molecular formula.

Operation: Each click on an element adds one atom to the formula.

Shortcuts: Shift+Click = remove one atom, Ctrl+Click = reset element count, Double-Click = add 10 atoms.

Real-Time Feedback: The current formula and its monoisotopic mass are displayed at the bottom of the panel.

3

Set Ion Charge

If necessary, adjust the ion charge state using the Charge +/- buttons.

Importance: Charge state affects the m/z calculation. For positive ions, m/z = mass/charge. For negative ions, appropriate corrections are applied.

Default: +1 charge (protonated molecule [M+H]+)

4

Visualize Simulation

The isotopic distribution simulation appears automatically in the elaborateur window.

Display: Red lines = theoretical isotopic distribution, Gray lines = experimental data.

Peak Shape: Adjust Width, Shape, and Asymmetry parameters to match your instrument's peak profile.

5

Calibrate (if needed)

If peaks do not align perfectly, use Recal for automatic calibration or Hard Recal for manual calibration.

Calibration Method: Least-squares fitting between theoretical and experimental peak positions.

Tolerance: Typical calibration errors should be < 1 ppm for high-resolution instruments.

6

Add to Aggregator

To compare multiple hypotheses, add each simulation to the agregador.

Process: Click "Add to agregator" button to copy the current simulation to the aggregator window.

Comparison: Repeat steps 2-5 for each molecular hypothesis, then visually compare in agregador.

Complete Example: Identifying an Unknown Molecule

Imagine you have a peak at m/z = 214.08485 in your experimental spectrum:

A

Analyze the Peak in DMVM

In the dmvm window, identify the peak with the highest intensity at m/z 214.08485.

Mass Defect: Calculate the mass defect: 214.08485 - 214 = +0.08485 Da

Interpretation: Positive mass defect suggests oxygen-containing compound (O has negative mass defect, but combinations with H, C, N can produce positive defects).

B

Initial Hypothesis

Try C10H10O4: Click 10x C, 10x H, 4x O in the periodic table.

Monoisotopic Mass Calculation:

C10: 10 x 12.000000 = 120.000000
H10: 10 x 1.007825 = 10.078250
O4: 4 x 15.994915 = 63.979660
Total: 194.057910 Da

Wait! This doesn't match! Let me recalculate...

C

Recalculate with Correct Formula

Actual C10H10O4 Calculation:

C10: 10 x 12.000000000 = 120.00000000
H10: 10 x 1.007825032 = 10.07825032
O4: 4 x 15.994914620 = 63.97965848
Total: 214.05790880 Da

Protonated [M+H]+: 214.05790880 + 1.007825032 = 215.06573383 Da

Correction: For [M]+− radical cation: 214.05790880 Da (matches experimental m/z 214.08485 within typical mass accuracy)

D

Compare Isotopic Profile

In elaborateur, compare the theoretical isotopic distribution with your experimental data.

Expected Pattern: For C10H10O4, the M+1 peak should be approximately 11% of the M peak (10 x 1.07% for 13C + 10 x 0.0115% for 2H = ~11.0%).

Validation: The isotopic pattern should match within the instrument's mass accuracy.

E

Confirm Assignment

If the match is good, the molecular formula is confirmed. If not, refine your hypothesis and repeat.

Refinement: Try different combinations of C, H, O, N, S based on the mass defect and isotopic pattern.

DBE Calculation: For C10H10O4: DBE = (2C + 2 - H + N - X)/2 = (20 + 2 - 10 + 0 - 0)/2 = 6. This indicates 6 rings + double bonds, consistent with aromatic compounds.

Advanced Features

Isotopic Distribution Simulation

Expert Note: Algorithm Details

Polynomial Multiplication: Attributor uses Fast Fourier Transform (FFT) to efficiently multiply the polynomial generating functions for each element. This reduces the computational complexity from O(n2) to O(n log n) for a molecule with n atoms.

Precision: Calculations use double-precision floating point (64-bit) for masses and intensities, providing >15 decimal digits of precision.

Threshold: The software applies an intensity threshold (default: 0.001% of base peak) to limit the number of displayed isotopic peaks and improve performance.

Dynamic Range: Can handle intensity ranges from 0.001% to 100% of the base peak, enabling visualization of both major and minor isotopologues.

Visualization Options

Peak Profiles

Gaussian: Symmetric bell-shaped peaks. Appropriate for most modern mass spectrometers (Orbitrap, TOF, QTOF).

Lorentzian: Peaks with broader tails. More appropriate for FT-ICR MS and some older instruments.

Hybrid: User-defined mix of Gaussian and Lorentzian profiles.

Scale Options

Linear: Direct intensity representation. Useful for comparing relative intensities of major peaks.

Logarithmic: Compresses dynamic range. Essential for revealing low-intensity isotopic peaks (e.g., M+2, M+3, M+4).

Square Root: Intermediate between linear and logarithmic, useful for moderate dynamic range.

Specialized Windows

panel2: Decomposition analysis for complex spectra

compare_attributions: Comparative analysis across multiple datasets

Molbag: Molecular database system for saving and recalling molecular formulas

Calibration System

Expert Note: Calibration Algorithms

Recal (Automatic): Uses iterative least-squares fitting between theoretical peak positions and experimental data. Converges to the best mass shift that minimizes the sum of squared differences.

Hard Recal (Manual): Allows direct input of calibration parameters: mass offset (in Da or ppm), linear scaling factor, and higher-order correction terms.

Multi-Point Calibration: Can use multiple identified peaks to establish a calibration curve, accounting for nonlinear mass scale distortions.

Internal Standards: Supports calibration using known internal standards with user-defined mass values.

Mass Defect Analysis (DMVM)

The DMVM (Defaut de Masse vs m/z) window provides advanced analysis capabilities:

  • Mass Defect Plot: Visualize mass defects as a function of m/z to identify elemental composition trends
  • Kendrick Mass Defect: Normalize mass defects based on CH2 units for hydrocarbon analysis
  • Homologous Series Identification: Identify series of compounds differing by repeated units (e.g., CH2, O)
  • ROI Selection: Define Regions Of Interest to focus on specific m/z ranges
  • Elemental Composition Filtering: Apply constraints based on expected elemental composition

Mathematical Algorithms

Isotopic Distribution Calculation

Attributor implements several algorithms for isotopic distribution calculation, optimized for different molecule sizes and complexity levels.

Expert Note: Algorithm Selection

Small Molecules (<20 atoms): Direct polynomial multiplication. Fast and precise for small molecules.

Medium Molecules (20-100 atoms): FFT-accelerated polynomial multiplication. Optimal balance of speed and precision.

Large Molecules (>100 atoms): Recursive convolution with thresholding. Handles memory constraints by limiting to significant isotopologues.

Threshold Parameter: Controls the minimum intensity cutoff (default: 0.001% of base peak). Lower thresholds provide more complete distributions but increase computation time.

Polynomial Generator Method

The primary algorithm uses generating functions for each element. For a molecule with nC carbon atoms, nH hydrogen atoms, etc.:

Ptotal(x) = [PC(x)]nC · [PH(x)]nH · [PN(x)]nN · [PO(x)]nO · ...

PC(x) = 0.9893 + 0.0107·x1.00335483507
PH(x) = 0.999885 + 0.000115·x1.00782503223-1.00782503223

Ptotal(x) = ∑ ak·xmk where ak = relative intensity, mk = mass shift

FFT Implementation: The convolution theorem states that the product of polynomials in the coefficient domain is equivalent to the convolution of their coefficient sequences in the index domain. FFT enables efficient computation: Ptotal = IFFT[FFT(PC)nC · FFT(PH)nH · ...]

Mass Calibration Algorithm

The calibration system uses a non-linear least-squares optimization to find the best mass shift parameter that aligns theoretical peaks with experimental data:

// Calibration objective function function calObjective(massShift, experimentalPeaks, theoreticalPeaks) { error = 0 for each theoretical peak p_theory at mass m_theory: m_experimental = findClosestPeak(experimentalPeaks, m_theory + massShift) if m_experimental exists: error += (m_theory + massShift - m_experimental)^2 / sigma^2 return error } // Minimize error using Levenberg-Marquardt algorithm massShift_optimal = minimize(calObjective, massShift_initial)

Error Messages Reference

Expert Note: Igor Pro Error Codes

Error -1: Wave not found. Cause: Referenced wave does not exist. Solution: Check that required data waves are loaded.

Error -2: Function not found. Cause: Procedure not compiled or missing. Solution: Verify MainProc.ipf is in correct location and compiled.

Error -3: Invalid parameter. Cause: Function called with incorrect parameters. Solution: Check function signature in MainProc.ipf.

Error -4: Memory allocation failed. Cause: Insufficient memory. Solution: Reduce problem size or increase available memory.

Error -5: File I/O error. Cause: Permission issues or missing files. Solution: Check file paths and permissions.

Check History: Always examine the History window for detailed error information and stack traces.

Performance Optimization

  • Reduce Molecule Size: For molecules with >100 atoms, consider breaking into smaller components
  • Increase Threshold: Use higher intensity thresholds (0.01-0.1%) for faster calculations
  • Limit Isotopes: For preliminary analysis, disable minor isotopes (e.g., 2H, 17O, 18O)
  • Use Linear Scale: For initial screening, linear scale is faster than logarithmic
  • Disable Graphics: Temporarily disable graph updates during batch processing
  • Close Unused Windows: Each graph window consumes memory; close unused windows

User Interface Overview

Attributor's interface consists of multiple specialized windows, each serving a distinct purpose in the molecular formula attribution workflow.

Window Descriptions

Periodic Table Panel (panel)

Position: Typically bottom-left
Primary Function: Interactive periodic table for building molecular formulas through element selection.

Display: Complete periodic table with color-coded element groups.

Interaction: Click to increment, Shift+Click to decrement, Ctrl+Click to reset, Double-Click for +10, Right-Click for context menu.

Elaborateur Window (elaborateur)

Position: Typically center
Primary Function: Main graph window displaying simulated isotopic distribution overlaid with experimental data.

Display: Logarithmic intensity scale vs m/z. Red lines = Theoretical simulation, Gray lines = Experimental data.

Aggregator Window (agregador)

Position: Typically center-right
Primary Function: Compare multiple isotopic simulations and overlay with experimental data.

Usage: Add simulations from elaborateur using the "Add to agregator" button.

DMVM Window (dmvm)

Position: Typically top-right
Primary Function: Mass Defect vs m/z analysis for detailed investigation of mass deviations.

Display: Scatter plot of mass defect values against m/z.

Advanced Manager Panel (AdvancedManager)

Position: Typically top-right (floating)
Primary Function: Advanced data management for loading and processing experimental spectra.

Supported Formats: Igor Pro binary (.ibw), ASCII text files with m/z and intensity columns.
