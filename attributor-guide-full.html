Welcome to Attributor

A powerful mass spectrometry tool developed at IPAG (Institut de Planétologie et d'Astrophysique de Grenoble, France) for molecular analysis and attribution.

Introduction

Attributor is a specialized software for Igor Pro designed to help researchers:

  • Interactively build molecular formulas via a comprehensive periodic table interface
  • Simulate isotopic distributions with high precision using advanced combinatorial algorithms
  • Compare simulated spectra with experimental data in real-time
  • Attribute molecular formulas to unknown mass peaks
  • Calibrate experimental data based on theoretical formulas
  • Analyze mass deviations using mass defect plots

Application Domain

Attributor is particularly useful in molecular astrophysics, analytical chemistry, and high-resolution mass spectrometry. It enables the identification and characterization of complex molecules from their mass spectra, taking into account the different possible isotopic combinations with precise natural abundances.

Key Scientific Concepts

Isotopic Distribution

Every element exists in nature as a mixture of isotopes with different masses. The natural abundance of each isotope affects the resulting mass spectrum pattern.

Example: Carbon has two stable isotopes: 12C (98.93%) and 13C (1.07%)

Mass Defect

The difference between the exact mass of an ion and its nominal (integer) mass. This value is characteristic for each element and helps in identification.

Formula: Mass Defect = Exact Mass - Round(Exact Mass)

Monoisotopic Mass

The mass of a molecule calculated using the exact mass of the most abundant isotope of each element (typically 12C, 1H, 16O, 14N, etc.).

Combinatorial Explosion

For a molecule with n atoms of an element that has k isotopes, there are (n+1)k-1 possible isotopic combinations!

Example: For C10H20O2:

  • Carbon: 10 atoms, 2 isotopes → 11 combinations
  • Hydrogen: 20 atoms, 2 isotopes → 21 combinations
  • Oxygen: 2 atoms, 3 isotopes → 3 combinations
  • Total: 11 × 21 × 3 = 723 possible combinations!

Optimization: Attributor uses the probability threshold to filter out unlikely combinations, making calculations feasible.

Probability Calculation

For each combination, Attributor calculates:

  1. Mass: Sum of isotope masses for that combination
  2. Probability: Product of individual isotope probabilities
  3. Binomial coefficient: Number of ways to achieve that combination

Final probability = Binomial coefficient × (Isotope probabilities product)

2. Combinatorial Calculation Algorithm

Mathematical Foundation: For a molecule with the formula CaHbNcOdSe..., the isotopic distribution is calculated using the polynomial multiplication method:

For each element: Pelement(x) = (p0 + p1·x + p2·x2 + ... + pn·xn)count Where: - pi = probability of isotope i - count = number of atoms of that element - x = mass shift variable Final distribution: Ptotal(x) = PC(x) × PH(x) × PN(x) × PO(x) × ... Example for C2H2: PC(x) = (0.9893 + 0.0107·x1.003355)2 PH(x) = (0.999885 + 0.000115·x1.006277)2 Ptotal(x) = PC(x) × PH(x)

3. Recursive Implementation

Attributor uses a recursive approach to efficiently calculate combinations:

Function: CalculateDistributions(elementList, currentIndex, currentMass, currentProbability) Base Case: if currentIndex == length(elementList): store result (currentMass, currentProbability) return Recursive Step: for each isotope of element[currentIndex]: for count from 0 to atomCount[currentIndex]: newProbability = currentProbability × (abundancecount) × C(atomCount, count) newMass = currentMass + count × isotopeMass CalculateDistributions(elementList, currentIndex+1, newMass, newProbability)

4. Probability Threshold Optimization

The Isotopic combo probability parameter (default: 0.01) controls which combinations are calculated:

  • If probability < threshold: Combination is excluded
  • Benefit: Reduces computation time from O(2n) to O(p×2n) where p is the probability threshold
  • Trade-off: Higher thresholds exclude rare combinations but improve speed
  • Recommended values:
    • 0.001: High precision, slow for large molecules (C>30)
    • 0.01: Good balance, default value
    • 0.1: Fast, may miss rare combinations

5. Binomial Coefficient Calculation

For efficiency, Attributor uses a pre-calculated table of binomial coefficients:

C(n, k) = n! / (k! × (n-k)!) Pre-calculation: For n from 0 to max_atoms (typically 100): For k from 0 to n: C[n][k] = C[n-1][k-1] + C[n-1][k] (Pascal's Triangle algorithm) Benefit: O(1) lookup instead of O(n) calculation per combination

6. Mass Calculation Precision

Attributor uses double-precision floating-point (64-bit) for all mass calculations:

  • Mass precision: ~15-17 decimal digits
  • Mass accuracy: Typically within 0.1 ppm (parts per million)
  • Limitations:
    • Floating-point rounding errors accumulate for very large molecules
    • For molecules with >50 heavy atoms, consider using integer arithmetic for exact masses

7. Monoisotopic Mass Calculation

The monoisotopic mass is calculated using the most abundant isotope of each element:

Mmono = Σ (ni × mmost_abundant,i) Where: - ni = number of atoms of element i - mmost_abundant,i = exact mass of most abundant isotope of element i Example for C6H12O6 (glucose): Mmono = 6 × 12.000000 + 12 × 1.007825 + 6 × 15.994915 Mmono = 72.000000 + 12.093900 + 95.969490 Mmono = 180.063390 u Ion charge correction: Mmono+ = Mmono + (charge × melectron) Mmono+ = Mmono - (charge × melectron) (for negative ions) Where melectron = 0.00054858 u

8. Peak Profile Generation

Simulated spectra are generated by convolving each isotopic peak with a peak shape function:

Gaussian-Lorentzian Hybrid: I(m) = (1-α) × G(m) + α × L(m) Gaussian component: G(m) = exp(-((m-μ)/σ)2/2) Lorentzian component: L(m) = 1 / (1 + ((m-μ)/γ)2) Parameters: - μ = peak center (calculated mass) - σ = Gaussian width (FWHM / 2√(2ln2)) - γ = Lorentzian width (FWHM / 2) - α = mixing parameter (0=Gaussian, 1=Lorentzian) FWHM calculation: FWHM = Width × √(m/z) / 1000 (typical for mass spectrometry)

9. Calibration Algorithm

The Recal and Hard Recal functions use a sophisticated calibration approach:

1

Find Closest Peak

Identify the experimental peak closest to the calculated monoisotopic mass.

Search radius:

  • Recal: ±0.5 Da
  • Hard Recal: ±2.0 Da
    • 2

    Calculate Mass Offset

    Calculate the difference between theoretical and experimental masses.

    Formula: Δm = mexp - mtheo

    3

    Apply Correction

    Shift the entire experimental spectrum by -Δm.

    Implementation: mexp,corrected(i) = mexp(i) - Δm

    10. Mass Defect Analysis Algorithm

    The dmvm window implements mass defect analysis for molecular identification:

    Mass Defect Definition: MD = mexact - round(mexact) For a molecule CcHhNnOoSs: MD = c×MD(C) + h×MD(H) + n×MD(N) + o×MD(O) + s×MD(S) Element Mass Defects: - H: +0.007825 - C: 0.000000 (reference) - N: +0.006450 - O: -0.005086 - S: -0.015640 - P: -0.015036 - Cl: -0.031147 / -0.034097 - Br: -0.024197 / -0.023257 Characteristic Patterns: - High positive MD: Many H atoms - Near zero: CHO compounds - Negative MD: Oxygen-rich or sulfur-containing - Very negative: Halogen-containing

    Algorithm Performance Considerations

    Computational Complexity:

    • Isotopic calculation: O(kn) where k = avg isotopes per element, n = total atoms
    • With threshold: O(p × kn) where p = probability threshold
    • Memory usage: O(2n) for storing all combinations

    Typical Performance:

    • C20H30O5: ~10,000 combinations, < 100ms
    • C30H40O10: ~100,000 combinations, < 500ms
    • C50H60O15: ~1,000,000 combinations, < 2s

    Optimizations:

    • Pre-calculated binomial coefficients
    • Probability threshold pruning
    • Symmetry exploitation for identical elements
    • Memory-efficient data structures

    • M+2 peak: m/z = 122.0640, intensity ≈ 0.5%

    Use DMVM for Mass Defect

    Switch to the dmvm window and locate the peak at m/z ≈ 120.0572.

    Mass defect calculation:

    • Mass defect = 120.0572 - 120 = +0.0572

    Interpretation:

    • Positive mass defect suggests hydrogen-rich or nitrogen-containing
    • Magnitude suggests mostly CHNO elements

    Estimate Molecular Formula

    Use the Mass Defect Method:

    Assume CxHyOz:

    • Mass defect equation: 0.007825y - 0.005086z ≈ 0.0572
    • Mass equation: 12x + 1.007825y + 15.994915z ≈ 120.0572

    6. This gives: 1.007825y ≈ -7.9326 (also impossible)

    📖 Tutorial 2: Complex Molecule with Multiple Elements

    Objective: Identify a molecule with a peak at m/z = 214.08485

    This is the example from the workflow section, solved in detail

    1

    Analyze Mass Defect

    m/z = 214.08485

    • Nominal mass = 214
    • Mass defect = 214.08485 - 214 = +0.08485

    Interpretation:

    • Positive MD: Hydrogen-rich or nitrogen-containing
    • Relatively high: Suggests many H or N atoms
    2

    Estimate from M+2 Peak

    Observe M+2 peak intensity in dmvm:

    • M peak: 100%
    • M+2 peak: ~35% of M peak

    M+2 peak sources:

    • Two 13C: For Cn, contribution = n(n-1)/2 × (1.07%)2 × 100%
    • One 18O: For Om, contribution = m × 0.205%
    • One 34S: For Sk, contribution = k × 4.25%
    • Two 15N: For Np, contribution = p(p-1)/2 × (0.364%)2 × 100%

    Calculate for C10H10O4:

    • Two 13C: 10×9/2 × (0.0107)2 = 45 × 0.00011449 = 0.005152 = 0.5152%
    • One 18O: 4 × 0.00205 = 0.0082 = 0.82%
    • Total M+2 ≈ 1.3352% (but we observed 35%!)

    Issue: M+2 is much higher than expected! This suggests elements with high natural abundance of +2 isotopes.

    Conclusion: Likely contains Cl (35% 35Cl, 24.24% 37Cl) or Br (50.69% 79Br, 49.31% 81Br)

    Tutorial Tips

    • Start with high-probability elements: C, H, O, N are most common in organic molecules
    • Use the mass defect: It's a powerful tool for narrowing down possibilities
    • Check the isotopic pattern: M, M+1, M+2 ratios are characteristic for different element combinations
    • Use calibration: Recal helps align theoretical and experimental masses
    • Build incrementally: Start with a core formula and add elements one at a time
    • Use the aggregator: Compare multiple hypotheses simultaneously
    • Check the database: If available, search known compounds with similar masses

    🐛 Troubleshooting Guide

    Common Issues and Solutions

    1

    Igor Pro Won't Launch

    Symptoms:

    • Double-clicking Igor64.exe does nothing
    • Error message appears briefly and disappears
    • Windows reports an error

    Solutions:

    • Check Igor Pro installation: Reinstall Igor Pro 64-bit
    • Check license: Ensure your Igor Pro license is valid
    • Run as administrator: Right-click Igor64.exe → Run as administrator
    • Check for conflicts: Close other Igor Pro instances
    • Check system requirements: Windows 7/10/11 64-bit, sufficient RAM

    Additional checks:

    • Verify Igor Pro is installed in a path without special characters
    • Check for antivirus software blocking Igor Pro
    • Try running from command line to see error messages
    2

    Project Won't Load

    Symptoms:

    • Error when opening ATTRIBUTOR 2022.pxp
    • Igor Pro hangs or crashes
    • History window shows compilation errors

    Solutions:

    • Check file location: Both ATTRIBUTOR 2022.pxp and MainProc.ipf must be in the same directory
    • Check file integrity: Verify both files are complete and not corrupted
    • Check permissions: Ensure you have read/write permissions for the directory
    • Try a different directory: Copy files to a simpler path (e.g., C:\Attributor)
    • Check Igor Pro version: Use Igor Pro 8.x or higher (64-bit)

    Error messages and their meanings:

    • "Function MainWindow not found": MainProc.ipf is missing or corrupted
    • "Wave not found": Required data wave is missing
    • "Syntax error": Code compilation failed, check Igor Pro version
    3

    Windows Don't Open Automatically

    Symptoms:

    • Only some windows open
    • Windows are minimized or hidden
    • No error messages but no visible windows

    Solutions:

    • Check Igor Pro History: Look for error messages in the History window
    • Manually open windows: Use Igor Pro menu → Windows to open hidden windows
    • Reset window positions: In Igor Pro: Windows → Tile Windows
    • Restart Igor Pro: Close and reopen the project
    • Check for multiple monitors: Windows may have opened on a non-existent monitor

    Window-specific issues:

    • panel not opening: May indicate a problem with the periodic table initialization
    • elaborateur not opening: May indicate graph window creation failed
    • dmvm not opening: May indicate missing data waves
    4

    Simulation is Slow or Hangs

    Symptoms:

    • Long calculation times for isotopic distributions
    • Igor Pro becomes unresponsive
    • Computer fans run at high speed

    Causes:

    • Large molecules: Many atoms lead to combinatorial explosion
    • Low probability threshold: Calculating too many combinations
    • Insufficient memory: 32-bit Igor Pro has memory limitations

    Solutions:

    • Increase probability threshold: Set to 0.01 or 0.1 for large molecules
    • Use 64-bit Igor Pro: 32-bit version has 2-4 GB memory limit
    • Reduce molecule size: Test with smaller formulas first
    • Close other applications: Free up memory
    • Use a faster computer: More CPU cores and RAM help

    Performance guidelines:

    • C20H30O5: ~10,000 combinations, fast
    • C30H40O10: ~100,000 combinations, < 1 second
    • C50H60O15: ~1,000,000 combinations, 1-2 seconds
    • C100H120O20: ~108 combinations, may be slow
    5

    Peaks Don't Align (Mass Calibration)

    Symptoms:

    • Theoretical and experimental peaks don't overlap
    • Mass differences are consistent across all peaks
    • Simulation is shifted relative to data

    Solutions:

    • Use Recal button: Click Recal to automatically calibrate
    • Use Hard Recal: For more aggressive calibration
    • Manual calibration: Adjust peak positions manually in Igor Pro
    • Check ion charge: Wrong charge state causes systematic mass shifts

    Calibration methods:

    • Linear calibration: Adjusts mass scale linearly
    • Quadratic calibration: Adjusts for non-linear mass scale (Hard Recal)
    • Reference peaks: Uses known peaks for calibration

    When calibration fails:

    • No peak found: Increase search radius or check if peak exists
    • Wrong peak selected: Manually verify the closest peak
    • Multiple peaks close: Use Hard Recal with broader search
    6

    Isotopic Pattern Doesn't Match

    Symptoms:

    • M, M+1, M+2 peak ratios don't match experimental data
    • Simulation looks different from data

    Causes:

    • Wrong molecular formula: The most common reason
    • Impure compound: Mixture of multiple compounds
    • Instrument resolution: Low resolution blurs isotopic pattern
    • Natural abundance variations: Non-standard isotopic abundances
    • Wrong charge state: Affects calculated masses

    Solutions:

    • Try different formulas: Use the aggregator to test multiple hypotheses
    • Check for mixtures: Use dmvm to identify multiple components
    • Adjust peak parameters: Change Width, Shape, Asymmetry in elaborateur
    • Consider instrument effects: Low-resolution instruments blur patterns

    M+2 peak diagnostic:

    • ~33% of M peak: One Cl atom
    • ~100% of M peak: One Br atom
    • ~5% of M peak: Two Cl atoms or one S atom
    • ~1.1% of M peak: Natural 13C2 contribution for Cn
    7

    Data Loading Issues

    Symptoms:

    • Experimental data doesn't appear in windows
    • Error when loading data files
    • Data appears but is corrupted or incomplete

    Solutions:

    • Check file format: Ensure data is in correct format (m/z and intensity columns)
    • Check file path: Use full path if file is not in Igor Pro directory
    • Check delimiters: Tab, comma, or space delimiters should be consistent
    • Check data range: Ensure m/z values are in expected range

    Supported formats:

    • Text files: .txt, .csv, .dat with m/z and intensity columns
    • Igor Pro binary: .ibw files
    • Other formats: Any format Igor Pro can import
    8

    Display Issues

    Symptoms:

    • Graphs don't display properly
    • Colors are wrong or missing
    • Fonts are too small or too large
    • Windows are too small or too large

    Solutions:

    • Reset display: In Igor Pro: ModifyGraph → Autoscale
    • Adjust colors: ModifyGraph → Appearance
    • Change font size: ModifyGraph → Axes → Labels
    • Resize windows: Drag window borders to resize
    • Reset defaults: Reinstall Attributor
    9

    Error Messages in History Window

    Common error messages and their meanings:

    Error Message Cause Solution
    Function not defined: MainWindow MainProc.ipf missing or corrupted Ensure MainProc.ipf is in the same directory as the .pxp file
    Wave not found: dataWave Experimental data not loaded Load data using AdvancedManager first
    Index out of range Trying to access data beyond wave dimensions Check data wave dimensions and indices
    Memory allocation failed Insufficient memory Close other applications, use 64-bit Igor Pro
    File not found Required file is missing Check file path and ensure all required files are present
    Division by zero Attempting to divide by zero Check input data for zero or invalid values
    Invalid type Wave type mismatch Ensure waves have correct type (float, etc.)
