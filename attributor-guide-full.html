Introduction

Attributor est un outil spécialisé pour Igor Pro 64-bit développé à l'IPAG Grenoble pour l'analyse et l'attribution des spectres de masse.

Il permet de :

  • Construire des formules moléculaires via un tableau périodique interactif
  • Simuler les distributions isotopiques théoriques avec précision
  • Comparer les spectres simulés aux données expérimentales
  • Calibrer les données expérimentales
  • Analyser les écarts de masse (DMVM)

Prérequis

  • Igor Pro 64-bit (WaveMetrics) installé
  • Windows 7/10/11

Installation

Les deux fichiers doivent être dans le même répertoire :

FichierDescriptionTaille
ATTRIBUTOR 2022.pxpProjet principal Igor Pro~55 Mo
MainProc.ipfCode source~813 Ko

Procédure :

  1. Lancer Igor64.exe
  2. Menu : File → Open → Open Experiment...
  3. Sélectionner ATTRIBUTOR 2022.pxp

Alternative : Glisser-déposer le fichier .pxp sur Igor64.exe

Workflow

  1. Charger les données : Utiliser AdvancedManager pour charger le spectre expérimental
  2. Construire la formule : Cliquer sur les éléments dans le tableau périodique
  3. Définir la charge ionique si nécessaire
  4. Visualiser : La simulation apparaît automatiquement dans elaborateur
  5. Calibrer : Utiliser Recal si les pics ne s'alignent pas
  6. Comparer : Ajouter à agregador pour comparer plusieurs hypothèses

Exemple :

Pour identifier une molécule avec un pic à m/z ≈ 214.08485 :

  1. Cliquer 10× C, 10× H, 4× O → Formule C10H10O4
  2. Vérifier que la masse monoisotopique ≈ 214.08485
  3. Comparer le profil isotopique dans elaborateur
  4. Utiliser Recal si nécessaire
  5. Ajouter à agregador pour comparaison

Dépannage

  • "Function not found" : Vérifier que MainProc.ipf est dans le même répertoire que ATTRIBUTOR 2022.pxp
  • Fenêtres non ouvertes : Vérifier la fenêtre History pour les erreurs
  • Simulation lente : Augmenter le seuil de probabilité des combinaisons isotopiques
  • Décalage de masse : Utiliser Recal, vérifier la charge ionique
