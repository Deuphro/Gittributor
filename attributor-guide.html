Bienvenue dans Attributor

Un outil puissant développé à l'IPAG (Institut de Planétologie et d'Astrophysique de Grenoble, France) pour l'analyse et l'attribution des spectres de masse en astronomie et chimie analytique.

Introduction

Attributor est un logiciel spécialisé pour Igor Pro conçu pour aider les chercheurs à :

  • Construire des formules moléculaires de manière interactive via un tableau périodique complet
  • Simuler les distributions isotopiques théoriques avec une précision élevée en utilisant des algorithmes combinatoires avancés
  • Comparer les spectres simulés avec les données expérimentales en temps réel
  • Attribuer des formules moléculaires à des pics de masse inconnus
  • Calibrer les données expérimentales en fonction des formules théoriques
  • Analyser les écarts de masse en utilisant des graphiques de défaut de masse

Domaine d'application

Attributor est particulièrement utile en astrophysique moléculaire, chimie analytique, et spectrométrie de masse haute résolution. Il permet d'identifier et de caractériser des molécules complexes à partir de leurs spectres de masse, en tenant compte des différentes combinaisons isotopiques possibles avec des abondances naturelles précises.

Concepts Scientifiques Clés

Distribution Isotopique

Chaque élément existe dans la nature sous forme d'un mélange d'isotopes de masses différentes. L'abondance naturelle de chaque isotope affecte le motif du spectre de masse résultant.

Exemple : Le carbone a deux isotopes stables : 12C (98,93%) et 13C (1,07%)

Défaut de Masse

La différence entre la masse exacte d'un ion et sa masse nominale (entière). Cette valeur est caractéristique pour chaque élément et aide à l'identification.

Formule : Défaut de Masse = Masse Exacte - Arrondi(Masse Exacte)

Masse Monoisotopique

La masse d'une molécule calculée en utilisant la masse exacte de l'isotope le plus abondant de chaque élément (généralement 12C, 1H, 16O, 14N, etc.).

Prérequis

1

Igor Pro 64-bit

Le logiciel nécessite Igor Pro version 64-bit (WaveMetrics) installé sur votre machine. Attributor utilise des fonctionnalités avancées d'Igor Pro pour le traitement des données et la visualisation.

Important : Les versions 32-bit ne sont PAS supportées en raison des limitations de mémoire avec les grands calculs de combinaisons isotopiques.

2

Système d'exploitation

Compatible avec Windows 7/10/11 (version 64-bit recommandée). Igor Pro est principalement disponible sur Windows.

3

Espace disque

Le fichier principal .pxp et ses dépendances nécessitent environ 10-20 Mo d'espace disque. Pendant le fonctionnement, les ondes temporaires peuvent utiliser de la mémoire supplémentaire.

Compatibilité des Versions d'Igor Pro

Attributor a été développé et testé avec les versions d'Igor Pro 8.x et supérieures. Pour une compatibilité optimale, utilisez la dernière version disponible d'Igor Pro 64-bit. Le code utilise des fonctionnalités modernes d'Igor y compris :

  • Opérations et manipulations d'ondes
  • Personnalisation des fenêtres graphiques
  • Contrôles de panneau et callbacks
  • Fonctions sécurisées pour le multithreading

Procédure d'Installation

1

Préparer les fichiers

Copiez le dossier Gittributor contenant ATTRIBUTOR 2022.pxp et MainProc.ipf dans un emplacement accessible sur votre machine.

Important : Les deux fichiers doivent être dans le même répertoire pour qu'Attributor fonctionne correctement.

2

Lancer Igor Pro 64-bit

Double-cliquez sur Igor64.exe pour lancer Igor Pro. Attendez que l'interface principale apparaisse.

Note : Assurez-vous qu'aucune autre instance d'Igor Pro ne fonctionne pour éviter les conflits.

3

Ouvrir le projet

Dans le menu Igor Pro :

  1. Cliquez sur Fichier
  2. Sélectionnez Ouvrir
  3. Choisissez Ouvrir Experiment...
  4. Naviguez et sélectionnez ATTRIBUTOR 2022.pxp

Alternativement, vous pouvez glisser-déposer le fichier .pxp sur l'exécutable Igor Pro.

4

Attendre le chargement

Le projet va charger toutes les procédures et initialiser les fenêtres. Cela peut prendre quelques secondes selon la performance de votre machine.

À quoi s'attendre :

  • Igor Pro va compiler tout le code dans MainProc.ipf
  • Plusieurs fenêtres vont s'ouvrir automatiquement
  • La fenêtre History peut montrer des messages de compilation

Premier Lancement

Lors du premier lancement, les fenêtres suivantes devraient s'ouvrir automatiquement :

  • panel - Panneau de contrôle principal avec tableau périodique
  • elaborateur - Fenêtre graphique principale pour la visualisation
  • agregador - Fenêtre de comparaison pour plusieurs simulations
  • dmvm - Fenêtre d'analyse de défaut de masse
  • AdvancedManager - Panneau de gestion des données

Personnaliser la Disposition des Fenêtres

Vous pouvez réorganiser les fenêtres en glissant leurs barres de titre. Pour sauvegarder votre disposition :

  1. Organisez les fenêtres comme vous le souhaitez
  2. Dans le menu Igor Pro : Windows → Save Window Layout...
  3. Donnez-lui un nom (ex: "Attributor Default")

Pour restaurer une disposition sauvegardée : Windows → Restore Window Layout

Problème de chargement ?

Si les fenêtres ne s'ouvrent pas automatiquement, vérifiez que :

  1. MainProc.ipf est dans le même répertoire que ATTRIBUTOR 2022.pxp
  2. Aucune erreur n'est affichée dans la fenêtre History
  3. Vous avez les permissions suffisantes pour exécuter Igor Pro
  4. Votre version d'Igor Pro est 64-bit et récente (8.x+)

Solution : Essayez de fermer et de rouvrir Igor Pro, puis ouvrez à nouveau le projet.

Interface Utilisateur

Description de l'Interface

L'interface d'Attributor comprend plusieurs fenêtres spécialisées qui fonctionnent ensemble pour fournir une expérience de travail complète.

🔢 Tableau Périodique (panel)

Position : En bas à gauche
Fonction : Contient le tableau périodique complet sous forme de boutons cliquables.

Chaque bouton représente un élément chimique (H, C, N, O, etc.).

📈 Élaborateur (elaborateur)

Position : Au centre
Fonction : Fenêtre graphique principale affichant le spectre de masse simulé superposé aux données expérimentales.

Affichage : Intensité en échelle logarithmique vs m/z (masse/charge)

🔄 Agrégateur (agregador)

Position : Au centre-droit
Fonction : Permet de comparer plusieurs simulations isotopiques et de les superposer aux données expérimentales.

➖ DMVM (dmvm)

Position : En haut à droite
Fonction : Affiche le défaut de masse vs m/z pour l'analyse détaillée des écarts de masse.

⚙️ AdvancedManager

Position : En haut à droite
Fonction : Panneau de gestion avancée pour charger et gérer les spectres expérimentaux.

Fenêtres Principales

Tableau Périodique

Grille de boutons organisée par période et groupe. Chaque clic sur un élément ajoute un atome à la formule moléculaire courante.

Fonctionnalités :

  • Cliquez pour incrémenter le nombre d'atomes
  • Feedback visuel montrant la formule courante
  • Éléments codés par couleur pour identification facile

Élaborateur

Fenêtre graphique principale montrant la distribution isotopique simulée superposée aux données expérimentales.

Contrôles :

  • Width : Paramètre de largeur des pics (FWHM)
  • Shape : Sélection de la forme des pics
  • Asym. : Paramètre d'asymétrie

Agrégateur

Fenêtre de comparaison pour superposer plusieurs simulations isotopiques.

Fonctionnalités :

  • Comparer plusieurs formules moléculaires
  • Évaluation visuelle du chevauchement
  • Contrôles de mise à l'échelle

DMVM

Analyse du défaut de masse vs m/z pour identifier les compositions moléculaires.

Fonctionnalités :

  • Calcul du défaut de masse
  • Points de données codés par couleur
  • Sélection de la ROI

Système de Codage par Couleurs

Attributor utilise un système de codage par couleurs :

  • Boutons Rouges : Actions destructives (Reset, Hard Recal)
  • Boutons Verts : Actions constructives (Add to agregator)
  • Lignes Rouges dans les graphes : Spectres théoriques simulés
  • Lignes Grises dans les graphes : Données expérimentales

Workflow

Workflow Standard

1

Charger les Données

Utilisez l'AdvancedManager pour charger vos données de spectre de masse expérimental.

Formats supportés :

  • Fichiers texte avec colonnes m/z et intensité
  • Format binaire Igor Pro (.ibw)
2

Construire la Formule

Cliquez sur les éléments dans le tableau périodique pour construire votre formule moléculaire.

Fonctionnement : Chaque clic sur un élément ajoute un atome à la formule.

3

Définir la Charge Ionique

Si nécessaire, ajustez la charge ionique.

Importance : Affecte la masse monoisotopique calculée.

4

Visualiser la Simulation

La simulation de distribution isotopique apparaît automatiquement dans la fenêtre elaborateur.

5

Calibrer (si nécessaire)

Si les pics ne s'alignent pas parfaitement, utilisez Recal ou Hard Recal.

6

Ajouter à l'Agrégateur

Pour comparer plusieurs hypothèses, ajoutez chaque simulation à l'agregateur.

Exemple Complet : Identification d'une Molécule Inconnue

Imaginez que vous avez un pic à m/z ≈ 214.08485 :

A

Analyser le Pic

Dans la fenêtre dmvm, identifiez le pic avec la plus haute intensité.

B

Hypothèse Initiale

Essayez C10H10O4 : Cliquez 10x C, 10x H, 4x O.

C

Vérifier la Masse

La masse monoisotopique calculée doit être proche de 214.08485.

D

Comparer le Profil

Dans elaborateur, comparez le profil isotopique.

Algorithme de Calcul Combinatoire

Pour une molécule CaHbNcOd..., la distribution isotopique est calculée via :

Ptotal(x) = PC(x) × PH(x) × PN(x) × PO(x) × ... Où Pelement(x) = (p0 + p1·x + p2·x2 + ...)count

Tutoriel Pas à Pas

Tutoriel 1 : Identification Moléculaire de Base

Objectif : Identifier une molécule avec un pic à m/z = 120.0572

1

Observer le Spectre

Dans elaborateur, examinez le spectre autour de m/z 120.

2

Utiliser DMVM

Dans dmvm, localisez le pic et notez sa masse exacte.

3

Estimer la Formule

Essayez C8H8O : 8×C, 8×H, 1×O.

4

Vérifier

Masse calculée : 120.0575. Comparez avec votre données.

Dépannage

Problèmes Courants

1

Igor Pro ne se lance pas

Solutions : Réinstallez Igor Pro 64-bit, exécutez en tant qu'administrateur.

2

Projet ne se charge pas

Solution : Vérifiez que MainProc.ipf est dans le même dossier que ATTRIBUTOR 2022.pxp.

Fenêtres ne s'ouvrent pas

Solution : Vérifiez la fenêtre History pour les erreurs.

Simulation lente

Solution : Augmentez le seuil de probabilité (0.01 → 0.1).
