Bienvenue dans Attributor

Un outil puissant développé à l'IPAG (Institut de Planétologie et d'Astrophysique de Grenoble) pour l'analyse et l'attribution des spectres de masse en astronomie et chimie analytique.

Introduction

Attributor est un logiciel spécialisé pour Igor Pro conçu pour aider les chercheurs à :

  • Construire des formules moléculaires de manière interactive via un tableau périodique
  • Simuler les distributions isotopiques théoriques avec une précision élevée
  • Comparer les spectres simulés avec les données expérimentales
  • Attribuer des formules moléculaires à des pics de masse inconnus
  • Calibrer les données expérimentales en fonction des formules théoriques

Domaine d'application

Attributor est particulièrement utile en astrophysique moléculaire, chimie analytique, et spectrométrie de masse haute résolution.

Interface Utilisateur

Description de l'interface (d'après votre capture d'écran)

Tableau Périodique (panel)

Position : Bas à gauche
Fonction : Grid de boutons pour chaque élément chimique (H, He, Li, C, N, O, etc.).

Élaborateur (elaborateur)

Position : Centre
Fonction : Spectre simulé (rouge/bleu) superposé aux données expérimentales (gris). Échelle log.

Agrégateur (agregateur)

Position : Centre-droit
Fonction : Compare plusieurs simulations isotopiques.

DMVM (dmvm)

Position : Haut à droite
Fonction : Défaut de masse (Mass defect) vs m/z. Analyse des écarts.

AdvancedManager

Position : Haut à droite
Fonction : Gestionnaire pour charger et gérer les spectres expérimentaux.

Fenêtres principales

Tableau Périodique

Grid de boutons organisés par période et groupe. Cliquez pour ajouter des atomes.

  • Sélection des éléments chimiques
  • Incrémentation/décrémentation du nombre d'atomes
  • Réinitialisation de la molécule
  • Réglage de la charge ionique

Élaborateur

Graphique principal : spectre simulé vs données expérimentales.

Contrôles : Width, Shape (Gaussien/Lorentzien), Asym., FWHM.

Agrégateur

Comparaison de plusieurs simulations superposées.

Menu : Use this list: Factors/Molbag

DMVM

Analyse du défaut de masse (difference entre masse théorique et expérimentale).

Contrôles : ROI size, IntCum %, InPnts, Depth of tree

Workflow d'Utilisation

1

Charger les données

Utilisez l'AdvancedManager pour charger vos données.

2

Construire la formule

Cliquez sur les éléments dans le tableau périodique.

3

Ajuster la charge

Réglez la charge ionique si nécessaire.

4

Visualiser

La simulation s'affiche dans elaborateur.

5

Calibrer

Utilisez Recal ou Hard Recal si besoin.

6

Ajouter à l'agrégateur

Ajoutez chaque simulation à l'agregateur.

Exemple : Identification d'une molécule

Si vous avez un pic à m/z = 214.0848526295296 :

A

Analyser le pic

Dans dmvm, notez la masse exacte.

B

Hypothèse initiale

Essayez C10H10O4 : cliquez 10x C, 10x H, 4x O.

C

Vérifier la masse

La masse calculée doit être proche de 214.08485.

D

Comparer le profil

Dans elaborateur, comparez le profil isotopique.

E

Affiner

Essayez d'autres combinaisons : C11H6O3, C9H14O5, etc.

F

Valider

Le profil isotopique doit correspondre parfaitement.

Conseils pour une identification rapide

  • Commencez simple : Peu d'hétéroatomes au début
  • Utilisez le défaut de masse : Fenêtre dmvm pour distinguer les éléments
  • Comparez les intensités : Rapport M/M+1/M+2 caractéristique
  • Utilisez les filtres : Ajustez le seuil dans dmvm
  • Sauvegardez : Save Experiment dans Igor Pro

Tutoriel Pratique

Scénario : Identification d'un composé organique

Vous avez un spectre de masse avec un pic principal à m/z ≈ 180.16.

1

Charger le spectre

Dans AdvancedManager, chargez votre fichier de données.

2

Analyser le défaut de masse

Dans dmvm, localisez le pic à m/z ≈ 180.16.

3

Formuler des hypothèses

Calculez rapidement : C10H12O3 = 180.0841 (très proche !)

4

Tester C10H12O3

Cliquez 10x C, 12x H, 3x O. Vérifiez dans elaborateur.

5

Comparer

Vérifiez que le profil isotopique correspond à vos données.

Résultat

Si le profil correspond, vous avez identifié votre molécule ! Sinon, ajustez la formule et réessayez.
