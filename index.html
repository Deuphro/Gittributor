Advanced Mass Spectrometry Formula Attribution Tool

Overview

ATTRIBUTOR is a specialized software tool developed for mass spectrometry data analysis, particularly focused on molecular formula attribution from high-resolution mass spectra. It enables researchers to identify and validate molecular compositions by analyzing isotopic patterns and mass-to-charge (m/z) ratios.

Originally developed at IPAG (Institut de Planétologie et d'Astrophysique de Grenoble) by François-Régis ORTHOUS-DAUNAY, ATTRIBUTOR is designed to assist scientists in astrophysics, cosmochemistry, and analytical chemistry in their research activities.

Molecular Formula Builder

  • Interactive element selection interface
  • Support for all periodic table elements
  • Visual representation of molecular composition
  • Charge state management (+/-)

Isotopic Pattern Simulation

  • Calculate isotopic distributions
  • Generate theoretical mass spectra
  • Multi-isotope combination analysis
  • Probability-weighted isotopic patterns

Spectral Analysis Tools

  • Data import and visualization
  • Peak detection and identification
  • Noise filtering algorithms
  • Comparison between theoretical and experimental spectra

Advanced Visualization

  • Multi-panel graph displays
  • Logarithmic and linear scaling
  • Customizable graph parameters
  • Export and save capabilities

Requirements

To run ATTRIBUTOR, you need:

  • Igor Pro 8.00 or later (required for long wave name support)
  • Windows operating system
  • Sufficient memory for mass spectrometry data processing

How to Run

Launch ATTRIBUTOR using the following command:

Igor64.exe ".\ATTRIBUTOR 2022.pxp"

Note: Make sure both files (ATTRIBUTOR 2022.pxp and MainProc.ipf) are in the same directory when running the software.
