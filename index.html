A guided workflow

From raw spectrum to auditable candidate.

ATTRIBUTOR is a workbench, not an automatic verdict. Each stage can be inspected, constrained, and revisited.

Load & activate

Import an X–Y mass/intensity file, select it in AdvancedManager, and make it the active spectrum or ROI.

Set the search

Choose ion charge, allowed elemental patterns, stoichiometric bounds, and the number of proposals to retain.

Generate formulas

Enumerate bounded factor combinations around the target m/z and rank them by signed mass error in ppm.

Simulate isotopes

Rebuild the complete isotope envelope, compare stick and profile traces, and inspect charge-corrected masses.

Review as a set

Compare formulas in the aggregator, inspect mass-defect patterns, propagate through graph families, and save useful lists.

Inside the calculations

Four engines, connected by the same mass model.

The central distinction is important: brute formula search proposes integer combinations; isotope simulation expands one formula; graph attribution connects measured peaks; Hough analysis searches for recurring linear relationships.

Reading the terminology. A “factor” is a stored stoichiometric pattern whose monoisotopic mass participates in the search. A “bag” is a named list of formula records with charge and target metadata. The same records can later drive the graph, ratio, and projection tools.
  1. 1
    Bound the chemistry first.

    Manual minima and maxima, or automatic maxima inferred from the target, prevent an unconstrained elemental universe.

  2. 2
    Search exact monoisotopic masses.

    The formula sieve initially uses each factor's most abundant isotope, not its full isotope envelope.

  3. 3
    Expand only the retained formulas.

    Isotope simulation is the expensive refinement step and therefore follows candidate generation.

  4. 4
    Keep the result set addressable.

    Lists retain mass bias, intensity, target information, and optional descriptive values for comparison.

01

Bounded formula attribution

Mixed-radix enumeration around one target m/z

trouvemass()

For selected factors, ATTRIBUTOR first sorts their monoisotopic masses and derives a maximum count for each from the charge-corrected target. The search then walks a cumulative-product (“mixed-radix”) index. All but the last factor are enumerated exhaustively; the final, heaviest factor is solved as the remainder needed to approach the target. When a branch has already overshot by half the final mass step, the index jumps over the whole invalid block instead of testing those rows.

After charge correction, each row becomes a stoichiometric proposal and an absolute signed ppm offset. The proposal list is sorted by that error, de-duplicated, and exposed for isotope simulation or review.

factorsboundsmixed radixppm rankproposals
What it does not promise: this is a bounded combinatorial sieve, not a universal molecular-identification oracle. Its result depends on the allowed factors, abundance/count limits, charge, and the target chosen.

02

Charge-aware isotope simulation

From one stoichiometry to a complete isotope envelope

genestringmol()

The formula builder produces a display string and calls the isotope sieve once for each element. For an element with n atoms and isotope-state occupancies ki, the probability is the multinomial term: the number of distinguishable ways to allocate the atoms, multiplied by the isotope abundances raised to those occupancies. Separate sieves cover elements with one through ten modeled isotopes.

Per-element mass/probability pairs are then combined across the molecule by adding mass and multiplying probability. A relative probability threshold removes weak local combinations before the final envelope is assembled. The simulator converts neutral mass to m/z for the selected charge, scales the envelope to the observed context, and produces sticks, an asymmetric profile, mass labels, ppm labels, and a mass-defect trace.

Σ kᵢ = n

mass(state) = Σ kᵢ · isotopeMassᵢ

m/z = (M − z · mₑ) / |z|
03

Graph Attribution

Connect peaks that differ by a selected compositional increment

GRAPHTTRIBUTOR

Graph Attribution starts from measured peaks, not from a finished formula list. One or more reference compositions are selected as “standards.” For every pair of peaks, ATTRIBUTOR measures the mass gap, finds the closest selected standard, and rejects gaps that do not match within the code's half-unit decision threshold. A surviving pair becomes an edge carrying both distance and the index of the compositional step.

kruskal4mass() sorts these edges by increasing distance. A union–find structure accepts an edge only when it joins two different components and respects a maximum node degree. This produces low-cost connected mass families instead of indiscriminately linking every nearby peak. Grow Forest permits unrestricted degree; Grow Reticles and Grow Grids build degree-limited structures and/or combine them. The results table summarizes the minimum-mass node, vertex count, and maximum intensity of each family.

Selecting a family can isolate its members as an ROI. A current target or a selected minimum-mass node can seed a formula, then a depth-first traversal adds or removes the stoichiometry and charge carried by each edge. “Forest to Bag” can retain families that meet vertex-count and ppm-seed criteria.

Configurable projections

One horizontal variable and two independent vertical panels are chosen from the same record fields.

  • Y panels: stoichiometry by element or the same target/bias/intensity/cost descriptors.

Operations

The operation window reuses the selected bags rather than creating a detached copy of the question.

Mass-defect space & Hough transform

Find a line before naming its chemistry.

The DMVM view places every spectral point at its signed mass defect, mass − round(mass). Molecular families that differ by a repeatable composition often become approximately linear in this coordinate system—even when the analyst has not supplied that composition in advance.

01 · vote

Every point pair casts one vote

For measured masses mi and defects di in the selected analysis population, ATTRIBUTOR derives the slope and intercept of the line passing through both points, then increments the matching accumulator cell.

02 · inspect

Read the locus and its marginals

The image shows accumulated evidence; side histograms show which slopes and intercepts are common. A tight bright locus means many measured pairs support the same linear relation.

03 · compare

Overlay reference compositions

A selected formula bag contributes reference slopes based on mass defect / mass. Matching lines make a candidate compositional increment easy to recognize; nonmatching lines remain visible as data.

04 · follow up

Move from pattern to attribution

Rectangular regions can be zoomed; marginal histograms update to the selection. The interface can send a selected parallelogram or nearby points to an ROI and launch attribution for the dominant connected segment.

∿

Why this is “pattern-agnostic”

Discovery starts from pairwise geometry, not a preselected formula

DMVM → slope/intercept

A homologous family with a roughly constant mass defect per mass unit produces a characteristic line in DMVM. Hough voting makes such a line visible even if its members are mixed among unrelated peaks. Reference composition lines are optional annotations, not a prerequisite for finding the locus.

The same discovery logic can seed formula search: a selected Hough region identifies a coherent population or segment, after which the bounded formula engine and isotope simulation test actual compositions against the data.

d(m) = m − round(m)

for points (mᵢ,dᵢ), (mⱼ,dⱼ):
s = (dⱼ − dᵢ) / (mⱼ − mᵢ)
b = dᵢ − s·mᵢ

Hough[s,b] += 1

Practical notes

What the interface does—and does not—promise.

Which data format does the basic loader expect?
The built-in loader reads an X–Y text file with mass and intensity columns and creates the active spectrum waves. Chromatogram-specific loading and COSIMA import are separate paths in the source.
How should the isotope probability threshold be read?
It is a relative threshold for each element: 0 retains every modeled local combination, while 1 retains the combination(s) at that element's maximum probability. Lower values trade computation for a broader envelope.
Does Graph Attribution cluster formulas directly?
No. It first builds a graph from measured peaks and reference mass gaps. A seed formula is then propagated along accepted graph edges. This distinction matters: the graph describes spectral connectivity, while a formula is a chemical interpretation of that connectivity.
Is the “Partitioning” operation complete?
The tab is present in the supplied interface, but its setup function is empty and no controls are created. This page labels it as a placeholder rather than presenting it as working functionality.
Are the Hough helpers all wired into the visible interface?
The visible Hough window uses the slope/intercept accumulator workflow shown above. A second set of streamlined Hough helpers exists in the source, but several of their interface functions are stubs; they are not advertised here as a separate finished workspace.
