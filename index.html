ATTRIBUTOR

Mass Spectrometry Molecular Formula Attribution & Isotopic Pattern Analysis

Overview

ATTRIBUTOR is a sophisticated Igor Pro-based software suite for high-resolution mass spectrometry data analysis, specializing in molecular formula attribution through advanced isotopic pattern recognition and statistical methods.

Developed by François-Régis ORTHOUS-DAUNAY at IPAG (CNRS/UJF Grenoble), ATTRIBUTOR integrates multiple analytical approaches: combinatorial formula generation, multinomial isotopic distribution simulation, Hough transform pattern detection, and Kruskal-based clustering for agnostic pattern discovery.

Graphical Interface Windows

ATTRIBUTOR operates through multiple coordinated windows, each serving a specific purpose in the mass spectrometry analysis workflow.

📊 Elaborateur (Main Analysis Window)

Primary spectrum visualization and theoretical vs. experimental comparison

  • Purpose: Display experimental mass spectrum (wave1stripped) alongside simulated isotopic patterns
  • Key Features: Logarithmic intensity scaling, mass defect visualization, error bars
  • Controls: Width, Shape, Asymmetry parameters for profile fitting
  • Traces: Multiple overlaid traces including data, simulation, and DMVM results
  • Color Coding: Data (grey), Simulation (red), DMVM (teal), Inco (purple)

🔬 Agregateur (Aggregation & Multi-Component Analysis)

Multi-molecular formula visualization and comparison with experimental data

  • Purpose: Aggregate multiple molecular formulas and compare with observed spectrum
  • Features: Tree-based representation, top bright masses display, ROI selection
  • Modes: Sticks (discrete peaks) or Profile (continuous) visualization
  • Interactivity: Logscale toggle, top N brightest mass display control
  • Tagging: Dynamic labeling of molecular formulas on the spectrum

🎯 DMVM (Defect Mass vs Mass Analysis)

Mass defect analysis for pattern recognition and validation

  • Purpose: Visualize mass defect (m/z - integer mass) to identify isotopic families
  • Axis: X = m/z, Y = Mass defect (with mirror symmetry)
  • Traces: DMVM simulation, ROI selection, theoretical tree masses
  • Tools: Depth of tree control, segment length measurement, intensity threshold
  • Clustering: Visual representation of molecular families in defect space

🔧 Panel (Element Selection Interface)

Interactive periodic table for molecular formula construction

  • Layout: Organized by element groups with color coding (H=dark grey, N=green, O=red, S=yellow)
  • Functionality: Click to add/subtract element counts, supports all 114 elements
  • Charge Control: Positive/negative ion state management
  • Real-time Update: Immediate formula generation and simulation

📈 Graphattribution (Advanced Formula Analysis)

Kruskal-based clustering and cost function optimization for formula ranking

  • Purpose: Evaluate and rank molecular formulas based on spectral matching
  • Metrics: Target mass, relative mass bias, intensity, stoichiometry, cost function
  • Visualization: Scatter plots with selectable X/Y axes
  • Clustering: Tree-based hierarchical organization of formulas
  • Operation Window: Access to advanced operations (DBE, Mass Zuba, etc.)

🔍 AdvMolManPanel (Advanced Molecular Manager)

Comprehensive molecular formula management and analysis workspace

  • Components: Panel (formula list), Graph (visualization), Oper (operations)
  • Formula List: Tabular display with Name, Mass, ppm error, Cost function
  • Selection Modes: Current, Decomposeur, Propagation, Tree (225 propositions), Variator
  • Graph Options: Stoichiometry, Target Mass, Intensity, Relative mass bias, Y=f(X), Cost function
  • Operations: Clustering, Ratio Plot, K-naries, Partitioning with selectable parameters

Core Algorithms

🧮 TrouveMass: Brute Formula Attribution

The trouvemass() function implements a combinatorial search algorithm for finding all possible molecular compositions that match a given mass within a specified tolerance.

Mathematical Foundation

Given a target mass mtarget and a set of atomic masses {p0, p1, ..., pn-1}, the algorithm solves the integer Diophantine equation:

m_target ≈ Σ (c_i × p_i) where c_i ∈ ℕ

Implementation Strategy:

  • Productive Cribbling: Uses cumulative products to generate all combinations exhaustively
  • prod[k] = prod[k-1] × (maxperm[k-1] + 1) - stretches the solution space
  • Degree of Freedom: The lightest element adjusts to fill mass gaps
  • Mass Tolerance: Configurable parameter (default: half the lightest element mass)
  • Optimization: Skips guaranteed overflow combinations to improve efficiency

Note: The algorithm ensures |m_calculated - m_target| < pmin/2 where pmin is the lightest element mass.

🎲 Multinomial Isotopic Simulation Engine

The genestringmol() → generesimu() → choisylecrible() pipeline implements a multinomial probability distribution for isotopic pattern simulation.

Multinomial Framework

For each element with k isotopes, the probability of a specific isotopic combination {n0, n1, ..., nk-1} is:

P = [Π C(n_i, a_i) × p_i^n_i] where C(n,a) = binomial coefficient

Implementation Details

  • Crible Functions (1-10): Handle elements with 1 to 10 isotopes using nested loops
  • choisylecrible(e, Z): Selects appropriate sieve based on isotope count
  • Probability Threshold: kriter parameter filters low-probability combinations (0=all, 1=most probable only)
  • Mass Calculation: Weighted sum of isotopic masses with natural abundances
  • Charge Correction: Electron mass adjustment (0.00054857990946 u)

genestringmol() Workflow

  1. Iterates through all 114 elements
  2. Builds molecular formula string with counts: H\B5\MC\B10\M
  3. Calls choisylecrible() for each present element
  4. Generates isotopic combinations via cribleN()
  5. Executes generesimu() to create final spectrum
  6. Updates simu_mass and simu_proba waves
  7. Scales to match experimental data intensity

🌳 Kruskal4Mass: Minimum Spanning Tree Clustering

The kruskal4mass() function implements a modified Kruskal's algorithm for clustering mass spectrometry features based on relationships and weights.

Algorithm Overview

  • Input: Observation matrix (obs), adjacency matrix (Adja), weights (Poids), parent tracking
  • Process: Sorts edges by weight, applies union-find to build minimum spanning tree
  • Features:
    • FindKruskal(k, parent) - Recursive parent finding with path compression
    • unionKruskal(a, b, parent) - Union operation for tree building
    • bayesianCut() - Statistical threshold determination
    • Degree-constrained merging (max degree parameter)
  • Output: Adjacency matrix representing clustered features

Application in ATTRIBUTOR

Used in graphttribution for organizing molecular formulas into hierarchical clusters based on mass relationships and spectral similarity.

Hough Transform Pattern Detection

ATTRIBUTOR implements the Hough Transform for agnostic pattern detection - identifying molecular families without prior knowledge of their composition.

🎯 Hough Transform Theory

The Hough Transform is a feature extraction technique that detects patterns by transforming data points into a parameter space where patterns become peaks.

Implementation in ATTRIBUTOR

  • NewHoughTransform(masse, minmax, reso):
    • Creates a 2D accumulator array (HoughMap) of size reso × reso
    • Maps each (m/z, intensity) point to parameter space
    • Accumulates votes for potential pattern centers
  • Hough Field Functions:
    • HoughField(w, x, y) - 2D Hough field fitting function
    • MultiHoughField(w, x, y) - Multi-dimensional extension
  • NewHoughSieve(nomdebag, prof):
    • Generates all possible molecular formulas from a bag
    • Creates Hough space representations
    • Filters based on mass defect and probability
    • Applies similarity scoring between formulas

Mathematical Formulation

For a molecular formula with atomic counts {c0, c1, ..., cn-1} and atomic masses {m0, m1, ..., mn-1}:

HoughMap[x][y] += 1 where x = ScaleToIndex(mass), y = ScaleToIndex(probability)

✨ Why Hough Transform?

The Hough Transform excels at detecting linear patterns in parameter space. In mass spectrometry, molecular families (homologous series, isotopic distributions) appear as linear sequences in m/z vs. mass defect space. The transform identifies these patterns without knowing the formula in advance, making it truly agnostic.

DMVM: Defect Mass vs Mass Pattern Analysis

The DMVM window implements a unique approach to pattern recognition by analyzing mass defect as a function of nominal mass.

📊 Mass Defect Concept

Mass defect is defined as the difference between the exact monoisotopic mass and the nearest integer mass:

mass_defect = exact_mass - round(exact_mass)

This value is particularly informative for identifying:

  • Isotopic families: Elements with specific isotope patterns (Cl, Br, S)
  • Heteroatom content: Nitrogen, oxygen, sulfur containing compounds
  • Homologous series: CH2 series in hydrocarbons, CO2 in organics
  • Charge states: +1, +2, -1 ions appear at characteristic defect positions

updateDistanceDMVM() Function

Calculates distances in defect space for pattern matching:

distance = f(mass_defect, nominal_mass)
  • Used for matching theoretical patterns to experimental data
  • Enables visualization of molecular families as clusters in defect space
  • Supports both stick (discrete) and profile (continuous) display modes

🎯 Pattern Agnostic Detection

The combination of DMVM + Hough Transform enables ATTRIBUTOR to:

  1. Detect unknown molecular families without formula knowledge
  2. Identify isotopic clusters (e.g., 35Cl vs 37Cl patterns)
  3. Discover homologous series in complex mixtures
  4. Validate formula attributions through pattern matching

AdvMolManPanel: Advanced Molecular Management

The Advanced Molecular Manager is a comprehensive workspace for managing, analyzing, and comparing multiple molecular formulas and their spectral signatures.

📋 Panel Component (AdvMolManPanelN)

Formula selection and list management

  • Formula List: Tabular display with columns: Name, Mass, dppm (mass error in ppm), Cost function
  • Selection Groups:
    • Current: Active working set (2 formulas)
    • Decomposeur: Decomposition analysis (4 formulas)
    • Propagations: Propagation results (0 formulas)
    • Factors: Factor analysis (6 formulas)
    • Propositions: Main proposition list (225 formulas)
    • Variator: Variation analysis (6 formulas)
  • Interactivity: Checkbox selection, highlight active formulas

📊 Graph Component (AdvMolManGraphN)

Multi-dimensional visualization and comparison

  • Axis Selection:
    • X-axis: Stoichiometry, Target Mass, Intensity, Relative mass bias, Y=f(X), Cost function
    • Y-axis: Same options plus "vs" comparison mode
  • Display Modes: Scatter plots with color coding by category
  • Overlay: Multiple formula traces on same axes
  • Interactive: Click to select, drag to zoom, double-click for details

As Shown in Screenshot:

  • Plot Type: Ratio Tree Oper0 vs Ratio Tree Oper0
  • Markers: Different shapes for each tree/molecule bag
  • Color Coding: Red circles, green circles, blue circles, purple squares
  • X-axis: Mass (150-300 m/z range)
  • Y-axis: 1+C+N/2-H/2 (stoichiometric ratio)

⚙️ Oper Component (AdvMolManOperN)

Advanced operations and analysis tools

  • Operation Types:
    • Clustering: Group formulas by similarity
    • Ratio Plot: Visualize stoichiometric ratios
    • K-naries: K-dimensional analysis
    • Partitioning: Divide into subsets based on criteria
  • Parameters: DBE, Mass Zuba, Meth (methylation), etc.
  • Tree Display: Hierarchical relationship visualization
  • Cost Function: Quantitative measure of formula quality

🔗 Integration Workflow

The three components work together seamlessly:

  1. Panel: Select formulas from proposition list
  2. Graph: Visualize relationships and patterns
  3. Oper: Perform advanced operations on selection
  4. Sync: All components update simultaneously on changes
